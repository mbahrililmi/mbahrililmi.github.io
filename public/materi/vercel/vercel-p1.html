Pengantar

Mengapa Deployment Penting?

Membuat aplikasi web yang bagus hanyalah separuh dari pekerjaan. Separuh lainnya adalah membuat aplikasi tersebut dapat diakses oleh pengguna di seluruh dunia. Deployment adalah proses memindahkan kode dari komputer lokal ke server yang dapat diakses publik secara 24/7, dengan performa tinggi dan downtime minimal.

Apa itu Vercel?

Definisi

Vercel adalah platform cloud yang fokus pada deployment frontend dan fullstack web applications secara instan, global, dan gratis untuk project personal. Vercel dikenal sebagai "the platform for frontend developers".

Fitur Unggulan Vercel

⚡ Zero Configuration
Deploy dengan satu perintah atau klik. Vercel otomatis mendeteksi framework (Next.js, React, Vue) dan mengkonfigurasi build settings.
🌐 Global Edge Network
Site didistribusikan ke 100+ data centers di seluruh dunia (Edge Network) untuk latency rendah ke semua pengguna global.
🔗 Preview Deployments
Setiap push ke Git branch otomatis mendapat unique URL preview. Tim bisa review perubahan sebelum merge ke production.
🔨 Serverless Functions
Backend API tanpa server management. Scale otomatis dari 0 ke jutaan request. Bayar hanya saat ada request.
📈 Analytics Built-in
Real User Monitoring (RUM), Core Web Vitals, Speed Insights langsung dari dashboard tanpa setup tambahan.
🔒 HTTPS Otomatis
SSL certificate gratis dan otomatis untuk semua domain (termasuk custom domain) menggunakan Let's Encrypt.

Siapa di Balik Vercel?

Sejarah Vercel

2015: Didirikan sebagai "ZEIT" oleh Guillermo Rauch (pencipta socket.io) dan tim.
2020: Rebranding menjadi "Vercel" dan meluncurkan Next.js 10.
2021: Raise $102M Series C, valuation $2.5 miliar.
2023: Series D $250M, Vercel AI SDK, v0 (generative UI).
Sekarang: Platform pilihan jutaan developer global.

Next.js & Vercel

Vercel adalah kreator dan maintainer utama Next.js — React framework terpopuler untuk production. Vercel dan Next.js saling terintegrasi sempurna: fitur Next.js baru (App Router, Server Components, Edge Runtime) dioptimalkan khusus di Vercel.

Cara Kerja Vercel

1. Push to Git

Developer push kode ke GitHub/GitLab/Bitbucket. Vercel otomatis mendeteksi perubahan dan memulai proses build.

2. Build & Optimize

Vercel menjalankan build command, mengoptimalkan assets (images, CSS, JS), dan meng-generate static files.

3. Deploy to Edge

Files didistribusikan ke 100+ edge nodes global. Request pengguna dilayani dari node terdekat untuk latency minimal.

Kapan Pilih Vercel?

✓ Cocok untuk Vercel
• Next.js applications
• React / Vue / Svelte apps
• Static sites & landing pages
• JAMstack applications
• Portfolio & blogs
• Frontend-heavy projects
✗ Pertimbangkan Alternatif
• Long-running processes (gunakan Railway/Render)
• WebSocket heavy (gunakan Railway)
• Traditional PHP/Laravel (gunakan Forge/Ploi)
• Need database built-in (gunakan Railway)
• Kompleks microservices (gunakan Kubernetes)

Ekosistem Vercel

Komponen Ekosistem Vercel

Vercel Platform
Core deployment platform. Hosting, CDN, Serverless Functions, Edge Network, Analytics.
Next.js
React framework yang dibuat oleh tim Vercel. App Router, Server Components, API Routes, ISR, streaming.
Vercel AI SDK
Library untuk membangun AI-powered apps. Streaming responses, chat UI, tool calling, multi-modal support.
v0 by Vercel
Generative UI tool. Buat komponen React/Tailwind dari deskripsi teks. AI-powered UI generation.
Vercel Storage
KV (Redis-like), Blob (file storage), Postgres (Neon integration), Edge Config (global config).
Vercel CLI
Command-line tool untuk deploy, dev server lokal, env management, dan project management dari terminal.

Praktikum

Setup Akun Vercel

Langkah pertama: buat akun dan eksplorasi dashboard Vercel.

Tugas Praktikum

1
Daftar Akun Vercel
  • Buka vercel.com → klik "Sign Up"
  • Login dengan akun GitHub (direkomendasikan untuk integrasi otomatis)
  • Pilih plan: Hobby (Free) untuk pembelajaran
  • Eksplorasi dashboard: Projects, Deployments, Domains, Analytics, Settings
  • Screenshot setiap halaman dashboard dan catat fungsinya
2
Riset & Perbandingan
  • Cek pricing Vercel (vercel.com/pricing) — apa saja batasan Hobby plan?
  • Bandingkan dengan Netlify free tier — mana lebih generous untuk project Anda?
  • Buat tabel perbandingan: Vercel vs Netlify vs Railway (min 5 aspek)
  • Simpulkan: kapan akan memilih Vercel untuk project nyata?
  • Deliverable: Dokumen perbandingan (PDF/Word, 1-2 halaman)
