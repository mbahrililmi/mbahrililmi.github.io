Vercel Analytics

Real User Monitoring (RUM)

Setup Analytics

1. Dashboard → Project → Analytics → Enable
2. Install package: npm install @vercel/analytics
3. Tambah ke layout:

// app/layout.tsx
import { Analytics } from '@vercel/analytics/react';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <Analytics />
      </body>
    </html>
  );
}
Data yang Tersedia

Traffic: Page views, unique visitors, sessions
Geography: Negara, kota asal pengunjung
Devices: Desktop, mobile, tablet
OS & Browser: Chrome, Safari, Firefox
Referrers: Dari mana pengunjung datang
Top Pages: Halaman paling sering dikunjungi

Speed Insights

Core Web Vitals Monitoring

LCP (Largest Contentful Paint)
Waktu loading elemen terbesar di layar. Target: < 2.5 detik. Pengaruh pada SEO Google.
FID (First Input Delay)
Responsiveness saat user pertama kali interaksi. Target: < 100ms. Menunjukkan interactivity.
CLS (Cumulative Layout Shift)
Stabilitas visual: seberapa banyak layout bergeser saat loading. Target: < 0.1.

Setup Speed Insights

# Install package
npm install @vercel/speed-insights

# app/layout.tsx
import { SpeedInsights } from '@vercel/speed-insights/next';

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <SpeedInsights />
      </body>
    </html>
  );
}

Function Logs

Debugging dengan Function Logs

// Tambahkan logging di function
// app/api/orders/route.ts
export async function POST(request: Request) {
  try {
    const body = await request.json();
    console.log('[Orders API] Request received:', JSON.stringify(body));
    
    // Process order...
    const order = await createOrder(body);
    
    console.log('[Orders API] Order created:', order.id);
    return Response.json({ success: true, orderId: order.id });
    
  } catch (error) {
    console.error('[Orders API] Error:', error);
    return Response.json(
      { error: 'Failed to create order' },
      { status: 500 }
    );
  }
}

// Lihat logs di:
// Dashboard → Project → Functions → click function → Logs
// Atau real-time: vercel logs --follow

Live Logs via CLI

# Real-time logs dari production
vercel logs --follow

# Filter by function
vercel logs --follow --filter="api/orders"

# Logs dari deployment tertentu
vercel logs https://my-app-xxxx.vercel.app

Performance Optimization

Best Practices Deployment Production

Image Optimization

Gunakan next/image untuk otomatis: WebP conversion, lazy loading, responsive sizes, blur placeholder. Jangan gunakan tag <img> biasa untuk gambar penting.

Bundle Size

Analisis dengan @next/bundle-analyzer. Import hanya yang dibutuhkan. Gunakan dynamic import untuk code splitting. Target: First Load JS < 200KB.

Caching Strategy

Static pages: cache selamanya. API responses: set Cache-Control headers. ISR: revalidate sesuai kebutuhan. Jangan cache data user-specific.

Security Headers

Tambahkan Content-Security-Policy, X-Frame-Options, X-Content-Type-Options di vercel.json headers. Scan dengan securityheaders.com.
