Apa itu Next.js?

Definisi Next.js

Next.js adalah React framework untuk production yang menyediakan: server-side rendering (SSR), static site generation (SSG), API routes, image optimization, routing berbasis file system, dan banyak lagi — out of the box.

Fitur Utama Next.js

App Router
Routing berbasis direktori app/. Server Components by default, nested layouts, loading states, error boundaries.
Server Components
Render di server, kirim HTML ke client. Akses database langsung, tidak perlu API endpoints untuk data fetching.
API Routes
Backend API dalam satu project. File di app/api/ menjadi serverless functions otomatis.
Image Optimization
Otomatis resize, compress, convert ke WebP/AVIF. Lazy loading bawaan. Serve dari CDN terdekat.
Streaming
Progressive rendering dengan React Suspense. User melihat konten lebih cepat tanpa menunggu seluruh halaman.
Middleware
Jalankan code di edge sebelum request diproses. Auth, redirects, A/B testing, geolocation.

Buat Next.js App

Membuat Project Next.js

# Buat project Next.js baru
npx create-next-app@latest my-next-app

# Wizard pertanyaan:
# Would you like to use TypeScript? No / Yes
# Would you like to use ESLint? Yes
# Would you like to use Tailwind CSS? Yes
# Would you like to use `src/` directory? No
# Would you like to use App Router? Yes
# Would you like to customize the default import alias? No

# Masuk ke folder dan jalankan dev server
cd my-next-app
npm run dev

# Buka http://localhost:3000

Struktur Project Next.js

my-next-app/
├── app/
│   ├── layout.tsx        # Halaman layout (navbar, footer, dll)
│   ├── page.tsx          # Halaman / (home)
│   ├── about/
│   │   └── page.tsx      # Halaman /about
│   └── api/
│       └── hello/
│           └── route.ts  # API endpoint /api/hello
├── public/               # Static assets (images, fonts)
├── components/           # Reusable React components
├── next.config.js        # Konfigurasi Next.js
├── tailwind.config.js    # Konfigurasi Tailwind
└── package.json

Deploy ke Vercel

Deploy Next.js via GitHub

# 1. Push ke GitHub
git init
git add .
git commit -m "Initial Next.js app"
git remote add origin https://github.com/username/my-next-app.git
git push -u origin main

# 2. Import di Vercel Dashboard
# vercel.com/new → Import Git Repository → pilih repo

# Atau deploy via CLI:
cd my-next-app
vercel

# Vercel otomatis mendeteksi: "Next.js"
# Build Command: next build
# Output Directory: .next
# Install Command: npm install

# Deploy ke production
vercel --prod
Zero-Config untuk Next.js

Vercel otomatis mendeteksi Next.js dan mengkonfigurasi semua yang dibutuhkan: build command, output directory, serverless functions dari API routes, image optimization, edge runtime, dan lainnya. Tidak perlu Dockerfile atau konfigurasi server.

Praktikum

Tugas Praktikum

1
Buat & Deploy Next.js App Pertama
  • Buat Next.js app: npx create-next-app@latest blog-app
  • Modifikasi app/page.tsx: tampilkan nama, NIM, dan deskripsi singkat
  • Buat halaman baru app/about/page.tsx dengan informasi diri
  • Tambah navigation di app/layout.tsx
  • Push ke GitHub dan deploy ke Vercel
  • Screenshot URL production dan catat fitur otomatis Vercel (HTTPS, domain, analytics)
2
API Route di Next.js
  • Buat app/api/hello/route.ts yang return JSON {message: "Hello World"}
  • Buat app/api/time/route.ts yang return current timestamp
  • Test di browser: your-site.vercel.app/api/hello
  • Cek Vercel Dashboard → Functions → lihat function invocations
