Selamat Datang di Mata Kuliah Big Data!

Di era digital ini, data menjadi aset paling berharga bagi organisasi. Setiap hari, miliaran perangkat menghasilkan data dalam jumlah yang sangat besar — dari transaksi e-commerce, media sosial, sensor IoT, hingga log server. Big Data bukan hanya tentang volume data yang besar, tetapi bagaimana mengekstrak nilai dan insight dari data tersebut untuk pengambilan keputusan yang lebih baik.

Mata kuliah ini membekali Anda dengan pemahaman fundamental tentang big data, lifecycle analytics, metode analitik (classification, prediction, clustering, association rules), tools big data (Hadoop, Docker, REST API), hingga implementasi studi kasus nyata di berbagai industri.

Apa itu Big Data?

Definisi

Big Data adalah kumpulan data yang sangat besar dan kompleks yang tidak dapat diproses dengan menggunakan tools database tradisional. Big Data ditandai dengan karakteristik 5V's: Volume, Velocity, Variety, Veracity, dan Value.

Karakteristik 5V's Big Data

Volume (Ukuran)
Data dalam jumlah sangat besar — terabyte, petabyte, bahkan exabyte. Contoh: Facebook menghasilkan 4PB data per hari.
Velocity (Kecepatan)
Kecepatan data dihasilkan dan diproses secara real-time atau near real-time. Contoh: Twitter menghasilkan 500 juta tweets per hari.
Variety (Keragaman)
Data dalam berbagai format — structured (database), semi-structured (JSON, XML), unstructured (video, image, text).
Veracity (Keakuratan)
Kualitas dan keandalan data. Data bisa tidak lengkap, tidak akurat, atau mengandung noise yang harus dibersihkan.
Value (Nilai)
Kemampuan mengekstrak insight dan nilai bisnis dari data. Big data harus menghasilkan actionable insights.
+ Variability
Perubahan makna data dalam konteks yang berbeda. Contoh: kata "bank" bisa berarti financial institution atau river bank.

Perbedaan Traditional Data vs Big Data

AspekTraditional DataBig Data
VolumeGigabytes - TerabytesPetabytes - Exabytes
ProcessingRelational Database (SQL)Distributed Computing (Hadoop, Spark)
StorageVertical Scaling (single server)Horizontal Scaling (cluster)
Data TypeStructured (tables)Structured, Semi-structured, Unstructured
SchemaSchema-on-writeSchema-on-read
AnalysisDescriptive analyticsPredictive & Prescriptive analytics

Fenomena Kemunculan Big Data

Mengapa Big Data Muncul Sekarang?
  • Digitalisasi: Semua aspek kehidupan ter-digitalisasi — transaksi, komunikasi, entertainment
  • Internet of Things (IoT): Miliaran sensor dan devices terkoneksi menghasilkan data terus-menerus
  • Mobile Devices: Smartphone & tablets menghasilkan location data, app usage, photos/videos
  • Social Media: Platform seperti Facebook, Instagram, Twitter, TikTok menghasilkan massive user-generated content
  • E-commerce: Transaksi online menghasilkan data perilaku konsumen, clickstream, purchase history
  • Healthcare: Electronic Health Records (EHR), medical imaging, genomic data
  • Scientific Research: Large Hadron Collider, climate modeling, astronomy data
Tantangan Big Data
• Storage: Menyimpan data dalam jumlah besar
• Processing: Memproses data dengan cepat
• Analysis: Mengekstrak insight yang berarti
• Security & Privacy: Melindungi data sensitif
• Data Quality: Memastikan akurasi dan konsistensi
• Skill Gap: Kebutuhan data scientist & engineers
Peluang Big Data
• Better Decision Making berbasis data
• Personalization & Customer Experience
• Fraud Detection & Risk Management
• Operational Efficiency & Cost Reduction
• New Business Models & Revenue Streams
• Innovation & Competitive Advantage
5

Framework & Ecosystem Big Data

  • Hadoop HDFS: Distributed file system untuk menyimpan data besar
  • Apache Spark: Fast in-memory processing framework
  • Apache Kafka: Distributed streaming platform
  • NoSQL Databases: MongoDB, Cassandra, HBase untuk unstructured data
  • Data Warehouses: Amazon Redshift, Google BigQuery, Snowflake
  • Data Lakes: Centralized repository untuk raw data (structured & unstructured)
  • Python: NumPy, Pandas, Scikit-learn untuk data analysis & ML
  • R: Statistical computing & graphics
  • Apache Mahout: Machine learning library di atas Hadoop
  • TensorFlow / PyTorch: Deep learning frameworks
  • Jupyter Notebook: Interactive data science environment
  • Tableau: Interactive data visualization platform
  • Power BI: Microsoft business intelligence tools
  • Apache Superset: Open-source data exploration platform
  • Matplotlib / Seaborn: Python visualization libraries
  • D3.js: JavaScript library untuk interactive visualizations

Karir di Bidang Big Data

Data Scientist
Analyze data, build models, extract insights. Skills: Python/R, ML, Statistics, Domain knowledge.
Data Engineer
Build data pipelines, manage infrastructure. Skills: Hadoop, Spark, SQL, Cloud (AWS/GCP/Azure).
Data Analyst
Analyze business data, create reports. Skills: SQL, Excel, Tableau/Power BI, Business acumen.
ML Engineer
Deploy ML models to production. Skills: Python, TensorFlow, Docker, Kubernetes, MLOps.
Big Data Architect
Design big data solutions. Skills: Distributed systems, databases, data modeling, cloud architecture.
Business Intelligence Developer
Develop BI dashboards & reports. Skills: SQL, ETL, data warehousing, visualization tools.

Praktikum Pertemuan 1

Latihan 1: Identifikasi Use Case Big Data
  • Pilih satu industri (e-commerce, healthcare, finance, transportation, atau retail)
  • Identifikasi 3-5 use case big data yang dapat diterapkan di industri tersebut
  • Untuk setiap use case, jelaskan:
    • Problem yang ingin diselesaikan
    • Jenis data yang dibutuhkan
    • Karakteristik 5V's yang relevan
    • Tools/teknologi yang dapat digunakan
    • Expected value/benefit
  • Deliverable: PDF report (3-5 halaman)
  • Format nama file: NIM_Nama_P1_BigDataUseCase.pdf
Latihan 2: Explorasi Tools Big Data
  • Install Python 3.x dan Jupyter Notebook
  • Install libraries: pandas, numpy, matplotlib
  • Download sample dataset (akan disediakan)
  • Load dataset menggunakan pandas dan lakukan exploratory data analysis sederhana
  • Buat simple visualization (chart/graph)
  • Export notebook sebagai HTML
  • Deliverable: Jupyter Notebook (.ipynb) + HTML export
