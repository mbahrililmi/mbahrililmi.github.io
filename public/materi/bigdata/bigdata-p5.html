K-Means Clustering

K-Means Clustering

K-Means adalah algoritma clustering yang membagi data menjadi K clusters berdasarkan kedekatan ke centroid. Setiap data point assigned ke cluster dengan centroid terdekat.

Cara Kerja:
1. Initialize K centroids secara random
2. Assign setiap point ke nearest centroid
3. Recalculate centroids (mean dari points dalam cluster)
4. Repeat step 2-3 hingga convergence

Elbow Method: Plot sum of squared distances vs K untuk menentukan optimal K (looking for "elbow" point).

3

Hierarchical Clustering

Hierarchical Clustering

Hierarchical Clustering membangun hierarchy of clusters tanpa perlu specify K upfront.

Agglomerative (Bottom-up):
• Start: Setiap point adalah cluster sendiri
• Iteratively merge closest pairs of clusters
• Result: Dendrogram tree structure

Linkage Methods:
• Single: Minimum distance between points
• Complete: Maximum distance
• Average: Average distance
• Ward: Minimize within-cluster variance

4

DBSCAN & Density-Based

DBSCAN & Density-Based

DBSCAN (Density-Based Spatial Clustering) adalah density-based algorithm yang dapat menemukan clusters dengan arbitrary shapes dan identify outliers.

Konsep Kunci:
• Eps (ε): Radius neighborhood
• MinPts: Minimum points untuk form dense region
• Core Point: Point dengan ≥ MinPts dalam ε radius
• Border Point: In ε radius of core point
• Noise: Points yang bukan core/border

Advantages: Tidak perlu specify K, handle outliers, find non-spherical clusters.

5

Evaluasi Clustering

Evaluasi Clustering

Metrics untuk Evaluate Clustering Quality:

1. Silhouette Score: Measure how similar object is to own cluster vs other clusters. Range [-1, 1]. Higher is better.
Formula: s(i) = (b(i) - a(i)) / max(a(i), b(i))

2. Davies-Bouldin Index: Average similarity ratio of each cluster with most similar one. Lower is better.

3. Within-Cluster Sum of Squares (WCSS): Sum of squared distances of points to centroids. Used in elbow method.

4. Calinski-Harabasz Index: Ratio of between-cluster to within-cluster dispersion. Higher is better.

Implementasi Python

from sklearn.cluster import KMeans, DBSCAN, AgglomerativeClustering
from sklearn.metrics import silhouette_score
import matplotlib.pyplot as plt

# K-Means dengan elbow method
wcss = []
for k in range(2, 11):
    kmeans = KMeans(n_clusters=k, random_state=42)
    kmeans.fit(X)
    wcss.append(kmeans.inertia_)

# Plot elbow curve
plt.plot(range(2, 11), wcss)
plt.xlabel('Number of Clusters')
plt.ylabel('WCSS')
plt.title('Elbow Method')
plt.show()

# Fit final model
kmeans_final = KMeans(n_clusters=4, random_state=42)
labels_kmeans = kmeans_final.fit_predict(X)

# DBSCAN
dbscan = DBSCAN(eps=0.5, min_samples=5)
labels_dbscan = dbscan.fit_predict(X)

# Evaluate
print(f"K-Means Silhouette: {silhouette_score(X, labels_kmeans):.3f}")
print(f"DBSCAN Silhouette: {silhouette_score(X, labels_dbscan):.3f}")
