Apa itu Data Ingestion?

Data Ingestion adalah proses mengumpulkan, mentransfer, dan memuat data dari berbagai sumber (databases, APIs, files, streaming) ke dalam sistem storage big data (HDFS, Data Lake, database). Ini adalah langkah pertama dan kritis dalam data pipeline.

Batch vs Stream Ingestion

Batch Ingestion

Mengumpulkan data dalam periode tertentu (setiap jam, hari, minggu) kemudian memproses sebagai satu batch. Cocok untuk reporting harian, ETL warehouse, dan workload yang toleran dengan latency tinggi.

Stream Ingestion

Memproses data secara real-time saat data tiba. Latency sangat rendah (milliseconds). Cocok untuk fraud detection, live dashboards, IoT monitoring, dan applications yang butuh immediate action.

Batch Ingestion

Cara Kerja Batch Ingestion

Data dikumpulkan dalam time window tertentu (jam/hari), kemudian diproses sekaligus sebagai satu batch. Tools: Apache Sqoop, Apache Airflow, Python ETL scripts, AWS Glue.

Tools Batch Ingestion

Apache Sqoop
Transfer data antara RDBMS (MySQL, PostgreSQL) dan Hadoop/HDFS. Efficient parallel transfer menggunakan MapReduce.
Apache Airflow
Workflow orchestration platform. Define ETL workflows sebagai DAGs (Directed Acyclic Graphs). Scheduling, monitoring, dan alerting terintegrasi.
Python ETL Scripts
Custom scripts menggunakan Pandas, SQLAlchemy, requests. Flexible tapi perlu maintenance lebih banyak. Cocok untuk simple ETL workflows.

Batch Ingestion dengan Python

import pandas as pd
import sqlalchemy
from pathlib import Path
import logging
from datetime import datetime, timedelta

logging.basicConfig(level=logging.INFO)

def batch_ingest_daily():
    """Ingest data harian dari database ke data lake"""
    yesterday = (datetime.now() - timedelta(days=1)).strftime('%Y-%m-%d')
    
    # Extract: baca dari source database
    engine = sqlalchemy.create_engine('mysql+pymysql://user:pass@host/db')
    query = f"""
        SELECT * FROM transactions 
        WHERE DATE(created_at) = '{yesterday}'
    """
    df = pd.read_sql(query, engine)
    logging.info(f"Extracted {len(df)} rows for {yesterday}")
    
    # Transform: basic cleaning dan transformation
    df['amount'] = pd.to_numeric(df['amount'], errors='coerce')
    df = df.dropna(subset=['customer_id', 'amount'])
    df['ingestion_date'] = datetime.now()
    
    # Load: simpan ke data lake (partitioned by date)
    output_path = f"data_lake/transactions/date={yesterday}/"
    Path(output_path).mkdir(parents=True, exist_ok=True)
    df.to_parquet(f"{output_path}data.parquet", index=False)
    logging.info(f"Loaded {len(df)} rows to {output_path}")
    
    return len(df)

if __name__ == "__main__":
    rows = batch_ingest_daily()
    print(f"Batch ingestion complete: {rows} rows")

Stream Ingestion

Real-Time Data Streaming

Stream ingestion memproses data secara real-time saat data tiba. Platform utama: Apache Kafka (message broker), Apache Flink/Spark Streaming (stream processing), AWS Kinesis (managed streaming).

Apache Kafka Architecture

Producer
Aplikasi yang mengirimkan (publish) messages ke Kafka topic. Contoh: website event tracker, IoT sensors, payment processor.
Broker (Kafka Cluster)
Server Kafka yang menerima, menyimpan, dan mendistribusikan messages. Messages disimpan dalam topics dengan partitioning dan replication.
Consumer
Aplikasi yang membaca (subscribe) messages dari topic. Contoh: fraud detection engine, real-time dashboard, notification service.

Kafka Producer & Consumer Python

from kafka import KafkaProducer, KafkaConsumer
import json
from datetime import datetime

# === PRODUCER: Kirim event transaksi ===
producer = KafkaProducer(
    bootstrap_servers=['localhost:9092'],
    value_serializer=lambda v: json.dumps(v).encode('utf-8')
)

# Simulasi event transaksi
transaction = {
    "transaction_id": "TXN-001",
    "customer_id": "C-123",
    "amount": 150000,
    "merchant": "Alfamart",
    "timestamp": datetime.now().isoformat()
}
producer.send('transactions', value=transaction)
producer.flush()
print("Transaction sent to Kafka!")

# === CONSUMER: Real-time fraud detection ===
consumer = KafkaConsumer(
    'transactions',
    bootstrap_servers=['localhost:9092'],
    value_deserializer=lambda v: json.loads(v.decode('utf-8')),
    auto_offset_reset='earliest'
)

for message in consumer:
    txn = message.value
    # Simple fraud check: amount > 5 juta
    if txn['amount'] > 5000000:
        print(f"⚠️  FRAUD ALERT: {txn['transaction_id']} - Rp{txn['amount']:,}")

Data Sources

Berbagai Jenis Data Sources

Data Ingestion pipeline harus dapat mengumpulkan data dari berbagai sumber yang heterogen — setiap sumber memiliki protokol, format, dan tantangan yang berbeda.

Kategori Data Sources

Relational Databases
MySQL, PostgreSQL, Oracle, SQL Server. Gunakan SQL queries dengan connection string. Tools: SQLAlchemy, JDBC/ODBC, Apache Sqoop untuk bulk transfer ke Hadoop.
REST APIs
JSON/XML via HTTP. Gunakan requests library atau httpx. Handle pagination, rate limiting, authentication (API key, OAuth). Contoh: Twitter API, weather API, financial data API.
File Systems
CSV, JSON, Parquet, ORC, Avro. Dari local disk, SFTP/FTP, S3/GCS/Azure Blob. Pandas + glob untuk batch file loading. PySpark untuk file besar.
Message Queues
Apache Kafka, RabbitMQ, AWS SQS. Real-time event streaming. Consumer groups untuk parallel processing. Durability dan at-least-once delivery guarantee.
IoT & Sensors
MQTT protocol untuk sensor data. AWS IoT, Azure IoT Hub. Frequency bisa sangat tinggi (1000+ events/detik). Butuh stream processing (Flink/Spark Streaming).
Web Scraping
BeautifulSoup + requests atau Scrapy framework. E-commerce price monitoring, news aggregation. Perhatikan robots.txt dan terms of service.

Python: Multi-Source Data Ingestion

import pandas as pd
import requests
import sqlalchemy
from pathlib import Path
import json

# === Source 1: REST API ===
def ingest_from_api(url, params=None, headers=None):
    """Ingest data dari REST API dengan pagination"""
    all_data = []
    page = 1
    while True:
        p = (params or {})
        p['page'] = page
        r = requests.get(url, params=p, headers=headers, timeout=30)
        r.raise_for_status()
        data = r.json()
        
        if not data.get('results'):
            break
        all_data.extend(data['results'])
        
        if not data.get('next'):  # No more pages
            break
        page += 1
    
    return pd.DataFrame(all_data)

# === Source 2: Database ===
def ingest_from_db(connection_str, query):
    """Ingest data dari relational database"""
    engine = sqlalchemy.create_engine(connection_str)
    with engine.connect() as conn:
        df = pd.read_sql(query, conn)
    return df

# === Source 3: Files (CSV/JSON/Parquet) ===
def ingest_from_files(pattern, format='csv'):
    """Ingest multiple files menggunakan glob"""
    files = list(Path('.').glob(pattern))
    dfs = []
    for f in files:
        if format == 'csv':
            dfs.append(pd.read_csv(f))
        elif format == 'json':
            dfs.append(pd.read_json(f))
        elif format == 'parquet':
            dfs.append(pd.read_parquet(f))
    return pd.concat(dfs, ignore_index=True)

# === Pipeline: Combine all sources ===
api_df = ingest_from_api('https://api.example.com/data')
db_df = ingest_from_db('postgresql://user:pass@host/db', 'SELECT * FROM orders')
files_df = ingest_from_files('data/*.csv')

combined = pd.concat([api_df, db_df, files_df], ignore_index=True)
print(f"Total records ingested: {len(combined)}")

Data Pipeline

Apache Airflow untuk Orchestrasi Pipeline

Apache Airflow adalah platform untuk authoring, scheduling, dan monitoring workflow. Workflows didefinisikan sebagai DAG (Directed Acyclic Graphs) menggunakan Python. Setiap task dalam DAG dapat dimonitor, di-retry, dan di-alert jika gagal.

Konsep Airflow

DAG
Directed Acyclic Graph mendefinisikan urutan dan dependencies antar tasks. Setiap DAG punya schedule (cron expression atau @daily, @hourly).
Operators
PythonOperator (run Python), BashOperator (run bash), SQLOperator (query DB), HTTPOperator (call API). Setiap operator = satu task.
Sensors
Operator khusus yang menunggu kondisi tertentu terpenuhi sebelum melanjutkan. FileSensor, S3KeySensor, ExternalTaskSensor.

Contoh Airflow DAG

from airflow import DAG
from airflow.operators.python import PythonOperator
from airflow.operators.bash import BashOperator
from datetime import datetime, timedelta
import pandas as pd

default_args = {
    'owner': 'bahril',

    'email_on_failure': True,
    'email': ['bahril@example.com'],
    'retries': 2,
    'retry_delay': timedelta(minutes=5),
}

# Define DAG
with DAG(
    'daily_sales_etl',
    default_args=default_args,
    description='Daily sales data ETL pipeline',
    schedule_interval='0 6 * * *',  # Setiap hari jam 6 pagi
    start_date=datetime(2024, 1, 1),
    catchup=False,
    tags=['sales', 'etl', 'bigdata'],
) as dag:

    # Task 1: Extract dari database
    def extract_sales(**context):
        date = context['ds']  # execution date (YYYY-MM-DD)
        df = pd.read_sql(f"SELECT * FROM sales WHERE date='{date}'", engine)
        df.to_parquet(f'/tmp/sales_{date}.parquet')
        print(f"Extracted {len(df)} rows for {date}")

    # Task 2: Transform data
    def transform_sales(**context):
        date = context['ds']
        df = pd.read_parquet(f'/tmp/sales_{date}.parquet')
        df['revenue'] = df['quantity'] * df['price']
        df['date'] = pd.to_datetime(df['date'])
        df.to_parquet(f'/tmp/sales_clean_{date}.parquet')
