REST API

REST API

RESTful Web Services untuk data access via HTTP.

Contoh REST API dengan Flask

from flask import Flask, jsonify, request
app = Flask(__name__)

data = [{'id':1,'name':'Alice'},{'id':2,'name':'Bob'}]

@app.route('/api/users', methods=['GET'])
def get_users():
    return jsonify(data)

@app.route('/api/users/', methods=['GET'])
def get_user(uid):
    user = next((u for u in data if u['id']==uid), None)
    return jsonify(user) if user else ('Not found', 404)

if __name__ == '__main__':
    app.run(debug=True)

Docker

Apa itu Docker?

Docker adalah platform containerization yang memungkinkan aplikasi dijalankan dalam container — environment yang isolated, lightweight, dan portable. Container berisi semua dependencies yang dibutuhkan aplikasi, sehingga "works on my machine" tidak lagi menjadi masalah.

Docker vs Virtual Machine

Virtual Machine (VM)

Full OS virtualization — setiap VM menjalankan OS lengkap di atas hypervisor. Berat (beberapa GB), boot lambat (menit), sangat isolated. Cocok untuk workload yang butuh full OS isolation atau OS berbeda.

Docker Container

OS-level virtualization — containers berbagi kernel host OS. Ringan (MB), boot sangat cepat (detik), portable. Cocok untuk microservices, big data apps, CI/CD pipeline, dan development environments.

Konsep Kunci Docker

Image
Blueprint read-only untuk container. Berisi OS base, dependencies, config, dan kode. Dibuat dari Dockerfile. Versi dapat di-tag (v1.0, latest).
Container
Running instance dari image. Isolated, memiliki filesystem sendiri, network, dan process space. Bisa di-start, stop, pause, delete.
Dockerfile
Script teks berisi instruksi untuk build image. Mendefinisikan base image, copy files, install dependencies, expose ports, dan run command.
Docker Hub
Registry publik untuk menyimpan dan berbagi Docker images. Mirip GitHub tapi untuk container images. Tersedia images resmi (Python, Hadoop, Kafka).
Docker Compose
Tool untuk mendefinisikan dan menjalankan multi-container applications menggunakan file docker-compose.yml. Cocok untuk stack development lokal.
Volume & Network
Volume untuk persistent storage (data tidak hilang saat restart). Network untuk komunikasi antar container dalam satu host.

Docker Commands & Dockerfile

# === Docker Basic Commands ===
docker pull python:3.10              # Pull image dari Docker Hub
docker images                        # List images
docker run -it python:3.10 bash      # Run container interactively
docker run -d -p 5000:5000 myapp     # Run detached, port mapping
docker ps                            # List running containers
docker ps -a                         # List all containers
docker stop container_id             # Stop container
docker rm container_id               # Remove container
docker logs container_id             # View container logs

# === Dockerfile untuk Flask Big Data App ===
# FROM python:3.10-slim
# WORKDIR /app
# COPY requirements.txt .
# RUN pip install -r requirements.txt
# COPY . .
# EXPOSE 5000
# CMD ["python", "app.py"]

# Build dan run image:
docker build -t bigdata-app:1.0 .
docker run -d -p 5000:5000 bigdata-app:1.0

Hadoop Ecosystem

Apa itu Apache Hadoop?

Apache Hadoop adalah open-source framework untuk distributed storage dan processing data dalam jumlah sangat besar menggunakan cluster of commodity computers. Hadoop memungkinkan memproses petabytes data yang tidak mungkin ditangani satu server.

Core Components Hadoop

KomponenFungsiKapan Digunakan
HDFSHadoop Distributed File System — menyimpan data besar di multiple nodes dengan replikasiMenyimpan raw data, log files, click streams dalam skala besar
MapReduceDistributed processing model: Map (filter/transform) + Reduce (aggregate)Batch processing data besar, word count, log analysis
YARNYet Another Resource Negotiator — resource management dan job schedulingMengalokasikan CPU/RAM untuk jobs di cluster
Apache HiveSQL interface untuk query data di HDFS (HiveQL)Data analyst yang familiar SQL bisa query big data
Apache SparkFast in-memory processing, 100x lebih cepat dari MapReduceReal-time analytics, ML, iterative algorithms
Apache KafkaDistributed streaming platform untuk real-time data pipelinesIoT data ingestion, event streaming, log aggregation

PySpark Quick Start

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, count, avg

# Buat Spark session
spark = SparkSession.builder     .appName("BigDataAnalysis")     .master("local[*]")      .getOrCreate()

# Load data dari HDFS atau lokal
df = spark.read.csv("hdfs:///data/sales.csv", header=True, inferSchema=True)

# Analisis penjualan per kategori
result = df.groupBy("category")     .agg(
        count("order_id").alias("total_orders"),
        avg("amount").alias("avg_amount"),
        col("amount").cast("double").alias("total")
    )     .orderBy("total_orders", ascending=False)

result.show(10)
result.write.parquet("hdfs:///output/sales_summary/")  # Save ke HDFS
spark.stop()

Cloud Platforms

Cloud vs On-Premise

Cloud Big Data

Kelebihan: Scalable (bayar sesuai pakai), managed (tidak maintain hardware), cepat setup, global availability, built-in HA
Kekurangan: Biaya tinggi untuk sustained workloads, latency ke cloud, data sovereignty, vendor lock-in

On-Premise Hadoop

Kelebihan: Full control data, predictable cost untuk large sustained workloads, data privacy, no internet dependency, customize hardware
Kekurangan: CAPEX tinggi, perlu tim ops, scaling lambat, tidak flexible
