Big Data di Retail & E-commerce

Industri retail dan e-commerce adalah salah satu pengguna terbesar big data. Setiap klik, transaksi, dan interaksi pelanggan menghasilkan data berharga. Perusahaan seperti Amazon, Tokopedia, Shopee menggunakan big data untuk semua aspek operasional mereka.

Use Cases Big Data di Retail

Customer Segmentation
Segmentasi pelanggan berdasarkan behavior (RFM, purchase patterns) untuk personalized marketing dan targeted promotions.
Product Recommendation
"You may also like" dan "Frequently bought together" menggunakan collaborative filtering dan association rules.
Dynamic Pricing
Penyesuaian harga real-time berdasarkan demand, competitor prices, dan inventory level. Digunakan Gojek, Grab untuk surge pricing.
Demand Forecasting
Prediksi kebutuhan stok minggu/bulan ke depan untuk mengoptimalkan inventory dan mengurangi stockout/overstock.
Fraud Detection
Deteksi transaksi mencurigakan secara real-time: fake reviews, payment fraud, account takeover.
Search Optimization
Improve search relevance dan ranking produk berdasarkan query patterns, click-through rate, dan purchase conversion.

import pandas as pd
import numpy as np
from datetime import datetime

# Load & merge data dari berbagai sumber
transactions = pd.read_csv('transactions.csv', parse_dates=['order_date'])
customers = pd.read_csv('customers.csv')
products = pd.read_csv('products.csv')

# Merge datasets
df = transactions.merge(customers, on='customer_id')                  .merge(products, on='product_id')

# Feature Engineering untuk Customer Analytics
today = pd.Timestamp.now()

# RFM Calculation
rfm = df.groupby('customer_id').agg(
    recency=('order_date', lambda x: (today - x.max()).days),
    frequency=('order_id', 'count'),
    monetary=('total_amount', 'sum')
).reset_index()

# Segmentasi based on percentile
rfm['R_score'] = pd.qcut(rfm['recency'], 4, labels=[4,3,2,1])  # Low = recent
rfm['F_score'] = pd.qcut(rfm['frequency'].rank(method='first'), 4, labels=[1,2,3,4])
rfm['M_score'] = pd.qcut(rfm['monetary'], 4, labels=[1,2,3,4])
rfm['RFM_score'] = rfm['R_score'].astype(str) + rfm['F_score'].astype(str) + rfm['M_score'].astype(str)

print(rfm.head())
print(f"Total customers: {len(rfm)}")
print(f"RFM Score distribution:
{rfm['RFM_score'].value_counts().head(10)}")

Data Quality Checks

Completeness
Check missing values per kolom. Target: <5% missing untuk kolom kritis (customer_id, amount, date). Impute atau drop berdasarkan threshold.
Consistency
Pastikan format konsisten: tanggal (ISO 8601), harga (Rupiah, bukan mix), category names (standardized, no typos).
Validity
Amount > 0, tanggal dalam range valid, customer_id ada di customer table. Identifikasi test transactions atau internal orders.
