Materi yang Diujikan

Big Data Tools (P9)

REST API Concepts

HTTP methods (GET/POST/PUT/DELETE), status codes (200, 201, 400, 404, 500), JSON request/response format, Flask routing dan endpoint design, RESTful API design principles.

Docker & Hadoop

Docker vs VM, konsep image/container/Dockerfile, perintah docker dasar, Hadoop ecosystem (HDFS, YARN, MapReduce, Hive, Spark), perbedaan Hadoop vs Spark, Cloud big data services.

Data Ingestion & Store (P11-P12)

Data Ingestion

Batch vs Stream ingestion (perbedaan, use cases, latency), Apache Kafka architecture (producer/broker/consumer/topic), Python ETL batch ingestion, tools: Sqoop, Airflow, Kafka.

Data Store

HDFS architecture (NameNode/DataNode, replication, blocks), NoSQL types (key-value, document, column, graph) dan use cases, OLAP vs OLTP, Data Lake vs Data Warehouse, Lakehouse (Delta Lake).

Studi Kasus (P13-P14)

Retail & E-commerce

RFM analysis (Recency, Frequency, Monetary), customer segmentation pipeline, association rules untuk product recommendation, churn prediction untuk retention, demand forecasting basics.

Healthcare, Finance & Ethics

Disease prediction (classification), fraud detection (anomaly detection + supervised), credit scoring, data privacy regulasi (UU PDP, GDPR, HIPAA), anonymization vs pseudonymization, ethical AI.

Contoh Soal

Contoh Soal Pilihan Ganda

Contoh Soal
  1. Docker container berbeda dengan Virtual Machine karena...
    A. Container tidak bisa menjalankan aplikasi Python
    B. Container berbagi kernel host OS sehingga lebih ringan
    C. Container membutuhkan hypervisor untuk berjalan
    D. Container hanya bisa digunakan di Linux
    Jawaban: B
  2. Dalam HDFS, komponen yang menyimpan metadata (lokasi blocks, permissions) adalah...
    A. DataNode   B. ResourceManager   C. NameNode   D. NodeManager
    Jawaban: C
  3. Apache Kafka digunakan untuk...
    A. SQL querying pada big data
    B. Real-time streaming data ingestion dan messaging
    C. Machine learning model training
    D. Visualisasi data interaktif
    Jawaban: B
  4. Perbedaan utama Data Lake vs Data Warehouse adalah...
    A. Data Lake lebih mahal dan hanya untuk data structured
    B. Data Warehouse menerima semua jenis data, Data Lake hanya structured
    C. Data Lake menyimpan semua jenis data (schema-on-read), DW hanya structured (schema-on-write)
    D. Tidak ada perbedaan, keduanya sama
    Jawaban: C

Contoh Soal Essay

Contoh Pertanyaan Essay
  1. Jelaskan arsitektur Apache Kafka dan peran Producer, Broker (Topic/Partition), dan Consumer dalam pipeline data streaming real-time. Berikan satu contoh use case konkret. (5 poin)
  2. Bandingkan batch ingestion vs stream ingestion: perbedaan, kelebihan/kekurangan masing-masing, dan kapan menggunakan yang mana. Berikan contoh tools untuk setiap pendekatan. (5 poin)
  3. Sebuah perusahaan fintech ingin membangun sistem fraud detection real-time. Jelaskan: (a) arsitektur data pipeline yang dibutuhkan, (b) metode analitik yang tepat, (c) aspek data privacy yang harus diperhatikan. (5 poin)
  4. Jelaskan konsep Data Lakehouse dan bagaimana ia menggabungkan keunggulan Data Lake dan Data Warehouse. Sebutkan minimal 2 teknologi open-source yang mendukung Lakehouse architecture. (5 poin)

Tips Ujian

Teori: Pahami Konsep
Jangan hafal, pahami mengapa suatu teknologi ada dan kapan digunakan. Gunakan analogi untuk ingat lebih mudah.
Coding: Struktur Dulu
Tulis comment/pseudocode dulu sebelum coding. Pastikan imports benar. Gunakan print() untuk debug. Partial credit lebih baik dari tidak ada jawaban.
Manajemen Waktu
Jangan terlalu lama di satu soal. Skip yang sulit, kembali setelah selesai yang lain. Alokasikan lebih banyak waktu untuk coding (60 poin).
