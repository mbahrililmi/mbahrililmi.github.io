Market Basket Analysis

Market Basket Analysis

Market Basket Analysis menemukan pola pembelian produk yang sering dibeli bersamaan. Contoh: "Customers who buy bread often buy butter".

Aplikasi:
• Product recommendation
• Store layout optimization
• Cross-selling strategies
• Promotional bundling

Frequent Itemsets: Set of items yang appear together dengan frequency ≥ minimum support threshold.

3

Apriori Algorithm

Apriori Algorithm

Apriori adalah algoritma untuk mining frequent itemsets dan generating association rules.

Implementasi Apriori

from mlxtend.frequent_patterns import apriori, association_rules
from mlxtend.preprocessing import TransactionEncoder
import pandas as pd

# Data transaksi
transactions = [
    ['bread', 'milk'],
    ['bread', 'diaper', 'beer', 'egg'],
    ['milk', 'diaper', 'beer', 'cola'],
    ['bread', 'milk', 'diaper', 'beer'],
    ['bread', 'milk', 'diaper', 'cola']
]

# Encode ke binary matrix
te = TransactionEncoder()
te_ary = te.fit(transactions).transform(transactions)
df = pd.DataFrame(te_ary, columns=te.columns_)

# Find frequent itemsets
frequent_itemsets = apriori(df, min_support=0.6, use_colnames=True)
print(frequent_itemsets)

# Generate rules
rules = association_rules(frequent_itemsets, metric="confidence", min_threshold=0.7)
print(rules[['antecedents','consequents','support','confidence','lift']])

Contoh Penggunaan

Setelah generate rules, filter berdasarkan metrics untuk actionable insights.

Metrics: Support, Confidence, Lift

Metrics: Support, Confidence, Lift

1. Support: Frequency of itemset in transactions
Support(A) = Count(A) / Total Transactions

2. Confidence: Likelihood of B given A
Confidence(A→B) = Support(A∪B) / Support(A)

3. Lift: Strength of association
Lift(A→B) = Confidence(A→B) / Support(B)
• Lift > 1: Positive correlation
• Lift = 1: Independent
• Lift < 1: Negative correlation
