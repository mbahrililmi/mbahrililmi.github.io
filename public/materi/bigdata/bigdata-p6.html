Apa itu Association Rule Mining?

Association Rule Mining adalah teknik unsupervised learning yang menemukan interesting relationships (rules) antara variabel dalam dataset transaksional yang besar. Teknik ini sangat populer di industri retail untuk mengetahui produk mana yang sering dibeli bersamaan.

Contoh rule: {Popok Bayi} → {Bir} — Ditemukan Walmart pada analisis transaksi Jumat malam. Ternyata ayah muda yang membeli popok cenderung juga membeli bir. Walmart memanfaatkan ini dengan menempatkan bir dekat rak popok, meningkatkan penjualan keduanya secara signifikan.

Menghitung dan menginterpretasikan tiga metrics utama: Support (frekuensi), Confidence (keandalan), dan Lift (kekuatan asosiasi). Menambahkan Leverage dan Conviction.

Market Basket Analysis

Definisi Market Basket Analysis

Market Basket Analysis (MBA) adalah penerapan association rule mining pada data transaksi retail untuk menemukan pola produk yang sering dibeli bersamaan dalam satu "keranjang belanja" (market basket).

Format Data untuk MBA

Transaction Data (Raw)

Format asli: Setiap baris = satu transaksi dengan list item yang dibeli.

Setelah encoding: Setiap kolom = satu item. 1 = dibeli, 0 = tidak dibeli. Diperlukan untuk algoritma.

Frequent Itemsets

Apa itu Frequent Itemsets?

Frequent Itemset adalah sekumpulan item yang muncul bersama dalam transaksi dengan frekuensi ≥ minimum support threshold yang ditentukan. Menemukan frequent itemsets adalah langkah pertama sebelum generate association rules.

  • 1-itemset: {bread} (Support=4/5=0.8), {milk} (0.8), {diaper} (0.8), {beer} (0.6), {cola} (0.4)
  • 2-itemset: {bread, milk} (0.6), {bread, diaper} (0.6), {milk, diaper} (0.6), {diaper, beer} (0.6)
  • 3-itemset: {bread, milk, diaper} (0.4) — frequency lebih rendah karena lebih spesifik
  • Apriori property: Jika itemset tidak frequent, semua superset-nya juga tidak frequent (prune)
3

Apriori Algorithm

Prinsip Apriori

Apriori Property (Anti-monotone): Jika sebuah itemset tidak frequent (support < min_support), maka semua superset-nya juga tidak frequent. Ini memungkinkan pruning yang efisien dalam candidate generation.

Langkah-Langkah Algoritma Apriori

Step 1: Scan & Count 1-itemsets

Scan seluruh database transaksi dan hitung frekuensi setiap individual item. Hapus item dengan support < min_support. Hasilnya adalah L₁ (frequent 1-itemsets).

Step 2: Generate Candidates (Cₖ)

Gabungkan frequent (k-1)-itemsets dari langkah sebelumnya untuk menghasilkan candidate k-itemsets (Cₖ). Prune kandidat yang mengandung subset tidak frequent.

Step 3: Scan & Prune

Scan database lagi untuk menghitung support setiap kandidat di Cₖ. Hapus kandidat dengan support < min_support. Hasilnya adalah Lₖ (frequent k-itemsets).

Step 4: Repeat Until Empty

Ulangi Step 2-3 untuk k = k+1 hingga tidak ada lagi frequent itemsets yang bisa dibentuk. Kemudian generate association rules dari semua frequent itemsets yang ditemukan.

Kelebihan & Kekurangan Apriori

✓ Kelebihan
• Mudah dipahami dan diimplementasikan
• Menggunakan Apriori property untuk pruning efisien
• Menghasilkan complete set of rules
• Banyak library tersedia (mlxtend, R arules)
✗ Kekurangan
• Multiple database scans (O(n) scan per level)
• Lambat untuk dataset besar dan banyak items
• Memory intensif untuk menyimpan candidates
• Solusi: Gunakan FP-Growth untuk dataset besar

Implementasi Apriori dengan Python

from mlxtend.frequent_patterns import apriori, association_rules
from mlxtend.preprocessing import TransactionEncoder
import pandas as pd

# === DATA TRANSAKSI SUPERMARKET ===
transactions = [
    ['roti', 'susu', 'mentega'],
    ['roti', 'popok', 'bir', 'telur'],
    ['susu', 'popok', 'bir', 'cola'],
    ['roti', 'susu', 'popok', 'bir'],
    ['roti', 'susu', 'popok', 'cola'],
    ['susu', 'bir'],
    ['roti', 'susu', 'popok'],
    ['roti', 'bir', 'cola'],
]

# Step 1: Encode ke binary matrix
te = TransactionEncoder()
te_array = te.fit(transactions).transform(transactions)
df_basket = pd.DataFrame(te_array, columns=te.columns_)
print("Binary Matrix:")
print(df_basket.head())

# Step 2: Find Frequent Itemsets
freq_items = apriori(
    df_basket,
    min_support=0.4,       # Minimal 40% dari transaksi
    use_colnames=True,
    max_len=None           # Tidak ada batasan panjang itemset
)
print(f"
Frequent Itemsets ({len(freq_items)} total):")
print(freq_items.sort_values('support', ascending=False))

# Step 3: Generate Association Rules
rules = association_rules(
    freq_items,
    metric="confidence",
    min_threshold=0.6      # Minimal confidence 60%
)
# Filter rules yang meaningful
rules = rules[rules['lift'] > 1.0]
rules_sorted = rules.sort_values('lift', ascending=False)

print(f"
Association Rules ({len(rules)} total):")
print(rules_sorted[['antecedents', 'consequents', 'support', 'confidence', 'lift']].to_string())

# Step 4: Analisis Rules Terbaik
print("
=== TOP 3 RULES BY LIFT ===")
for _, row in rules_sorted.head(3).iterrows():
    ant = ', '.join(list(row['antecedents']))
    con = ', '.join(list(row['consequents']))
    print(f"{{'{ant}'}} → {{'{con}'}}")
    print(f"  Support: {row['support']:.2f} | Confidence: {row['confidence']:.2f} | Lift: {row['lift']:.2f}")

FP-Growth Algorithm

Mengapa FP-Growth?

FP-Growth (Frequent Pattern Growth) mengatasi kelemahan Apriori dengan hanya 2x scan database dan menggunakan struktur tree (FP-Tree) yang compact. Lebih efisien untuk dataset besar tanpa candidate generation.

Perbedaan Apriori vs FP-Growth

AspekAprioriFP-Growth
Database ScansMultiple (k+1 scans)Hanya 2 scans
Candidate GenerationYa (dapat sangat banyak)Tidak perlu
Memory UsageTinggi (menyimpan candidates)Compact (FP-Tree)
SpeedLambat untuk data besarLebih cepat (2-10x)
ImplementasiSederhanaLebih kompleks
Cocok untukDataset kecil/medium, pembelajaranDataset besar, production

FP-Tree: Struktur Data FP-Growth

Cara Kerja FP-Growth

Langkah 1: Build FP-Tree
Scan database sekali untuk hitung item frequency. Scan kedua untuk build kompressed prefix-tree dari transaksi (hanya item frequent yang dimasukkan, diurutkan dari frekuensi tertinggi).

Langkah 2: Mine FP-Tree
Untuk setiap item frequent, bangun "conditional pattern base" (prefix paths berakhir di item tersebut), kemudian mine frequent itemsets dari conditional FP-tree secara rekursif.

Implementasi FP-Growth Python

from mlxtend.frequent_patterns import fpgrowth, association_rules
import pandas as pd

# FP-Growth lebih efisien dari Apriori untuk dataset besar
# Menggunakan df_basket yang sudah dibuat sebelumnya

# Mine dengan FP-Growth
freq_items_fp = fpgrowth(
    df_basket,
    min_support=0.4,
    use_colnames=True
)

print(f"FP-Growth found {len(freq_items_fp)} frequent itemsets")

# Generate rules (sama seperti Apriori)
rules_fp = association_rules(
    freq_items_fp,
    metric="lift",
    min_threshold=1.2      # Gunakan lift sebagai primary metric
)

print(f"
Rules with Lift > 1.2: {len(rules_fp)}")
print(rules_fp[['antecedents','consequents','support','confidence','lift']].head(10))

# Visualisasi scatter plot rules
import matplotlib.pyplot as plt

plt.figure(figsize=(10, 6))
plt.scatter(
    rules_fp['support'],
    rules_fp['confidence'],
    alpha=0.6,
    c=rules_fp['lift'],
    cmap='YlOrRd',
    s=100
)
plt.colorbar(label='Lift')
plt.xlabel('Support')
plt.ylabel('Confidence')
plt.title('Association Rules: Support vs Confidence (colored by Lift)')
plt.grid(True, alpha=0.3)
plt.show()

Metrics: Support, Confidence, Lift

Mengukur Kualitas Association Rules

Tidak semua association rules yang ditemukan bermanfaat secara bisnis. Kita perlu metrics untuk mengukur kualitas dan kekuatan setiap rule. Tiga metrics utama adalah Support, Confidence, dan Lift.

Tiga Metrics Utama

Support

Formula:
Support(A→B) = Freq(A∪B) / N

Interpretasi: Seberapa sering rule ini muncul dalam dataset. Rule dengan support rendah mungkin kurang reliable karena didasarkan pada sedikit transaksi.

Range: [0, 1]
Rekomendasi: min_support ≥ 0.01 (1%)

Confidence

Formula:
Conf(A→B) = Support(A∪B) / Support(A)

Interpretasi: Seberapa sering B muncul ketika A muncul. Confidence = 0.8 berarti 80% transaksi yang mengandung A juga mengandung B.

Range: [0, 1]
Rekomendasi: min_confidence ≥ 0.5 (50%)

Lift

Formula:
Lift(A→B) = Conf(A→B) / Support(B)

Interpretasi: Seberapa kuat asosiasi dibanding random.
• Lift > 1: A meningkatkan kemungkinan B
• Lift = 1: A dan B independen
• Lift < 1: A menurunkan kemungkinan B
Rekomendasi: Lift ≥ 1.2

Metrics Tambahan

Leverage

Formula: Leverage(A→B) = Support(A∪B) − Support(A) × Support(B)

Interpretasi: Perbedaan antara observed frequency dan expected frequency jika A dan B independent. Leverage = 0 → independent. Leverage > 0 → positive association.

Keunggulan: Tidak bias terhadap itemsets dengan high support seperti Lift.

Conviction

Formula: Conv(A→B) = (1 − Support(B)) / (1 − Confidence(A→B))

Interpretasi: Mengukur derajat implication. Conviction → ∞ berarti rule sangat reliable. Conviction = 1 → A dan B independent.

Keunggulan: Direksional (berbeda dengan Lift yang simetris). Lebih baik untuk causal analysis.

Contoh Kalkulasi Manual

Hitung Metrics untuk Rule: {roti} → {susu}

Dari 8 transaksi dataset kita:
• Freq({roti}) = 5 → Support(roti) = 5/8 = 0.625
• Freq({susu}) = 5 → Support(susu) = 5/8 = 0.625
• Freq({roti, susu}) = 3 → Support(roti∪susu) = 3/8 = 0.375

Support(roti→susu) = 0.375
Confidence(roti→susu) = 0.375 / 0.625 = 0.6 (60%)
Lift(roti→susu) = 0.6 / 0.625 = 0.96 (sedikit negatif!)
Leverage = 0.375 - (0.625 × 0.625) = 0.375 - 0.390 = -0.015

→ Rule ini memiliki confidence OK tapi lift < 1, artinya membeli roti justru sedikit mengurangi kemungkinan membeli susu.

Aplikasi Lanjutan

Sequential Pattern Mining

Association Rules vs Sequential Patterns

Association rules menemukan items yang co-occur dalam satu transaksi. Sequential Pattern Mining menemukan pola yang muncul dalam urutan waktu tertentu.

Contoh: Pelanggan yang membeli kamera digital → (30 hari kemudian) → membeli kartu memori → (60 hari kemudian) → membeli album foto.

Aplikasi: prediksi next purchase, targeted email campaigns, product lifecycle analysis.

Strategi Bisnis dari Association Rules

Cross-Selling
Sarankan produk yang sering dibeli bersamaan saat pelanggan melihat produk tertentu. "You might also need..." di product page.
Up-Selling
Gunakan rules untuk merekomendasikan versi premium atau ukuran lebih besar. "Customers who bought this also preferred the premium version..."
Bundle Pricing
Buat bundle discount untuk items dengan high association. Strategi ini meningkatkan AOV (Average Order Value) secara signifikan.
Store Layout
Optimasi penempatan produk di rak (supermarket) atau halaman web (e-commerce). Products dengan high lift ditempatkan berdekatan.
Inventory Management
Produk yang sering dibeli bersamaan harus selalu tersedia bersamaan. Stockout satu item dari bundle akan mengurangi penjualan item lainnya.
Email Personalization
Kirim email rekomendasi berdasarkan purchase history. "Anda beli X, pelanggan serupa juga sering membeli Y dan Z. Cek sekarang!"

End-to-End Pipeline MBA

import pandas as pd
from mlxtend.frequent_patterns import fpgrowth, association_rules
from mlxtend.preprocessing import TransactionEncoder

# === LOAD DATA DARI DATABASE / CSV ===
# Asumsikan data POS (Point of Sale) dari toko retail
pos_df = pd.read_csv('transactions.csv')
# Format: transaction_id, product_name, quantity, price, date

# === PREPARE TRANSACTIONS ===
# Group items per transaction
basket = pos_df.groupby('transaction_id')['product_name'].apply(list).reset_index()
transactions = basket['product_name'].tolist()

# === ENCODE TO BINARY MATRIX ===
te = TransactionEncoder()
te_array = te.fit(transactions).transform(transactions)
df_encoded = pd.DataFrame(te_array, columns=te.columns_)

print(f"Transactions: {len(df_encoded)}")
print(f"Unique products: {len(df_encoded.columns)}")

# === MINE FREQUENT ITEMSETS ===
# Gunakan FP-Growth untuk dataset besar
freq_items = fpgrowth(df_encoded, min_support=0.02, use_colnames=True)
print(f"Frequent itemsets: {len(freq_items)}")

# === GENERATE RULES ===
rules = association_rules(freq_items, metric='lift', min_threshold=1.5)
rules = rules[rules['confidence'] >= 0.5]
rules = rules.sort_values('lift', ascending=False)

# === BUSINESS INTERPRETATION ===
print("
=== TOP 10 PRODUCT BUNDLES ===")
for i, row in rules.head(10).iterrows():
    ant = list(row['antecedents'])
    con = list(row['consequents'])
    print(f"Jika beli: {ant}")
    print(f"   → Rekomendasikan: {con}")
    print(f"   Support: {row['support']:.3f} | Confidence: {row['confidence']:.3f} | Lift: {row['lift']:.2f}")
    print()
